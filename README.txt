# Plantilla de verificación de certificado

Esta plantilla está pensada para GitHub Pages y utiliza una identidad visual genérica.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño.
- `app.js`: datos editables.
- `documento.pdf`: reemplázalo por tu PDF real.
- `assets/logo-placeholder.svg`: reemplázalo por tu logo.
- `assets/pdf-icon.svg`: icono del botón PDF.

## Para cambiar los datos
Abre `app.js` y modifica únicamente el bloque `const datos = { ... }`.

## Para usar tu logo
Reemplaza `assets/logo-placeholder.svg` por tu imagen.
Si tu archivo se llama `logo.png`, cambia en `index.html`:
`assets/logo-placeholder.svg` por `assets/logo.png`.

## Para usar tu PDF
Sube el PDF con el nombre `documento.pdf` o cambia `archivoPDF` dentro de `app.js`.

## GitHub Pages
Sube todos estos archivos a la raíz del repositorio.
Después:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

Nota: la plantilla es una recreación genérica de una interfaz de consulta de certificados; usa tu propia marca y datos.
Página configurada en GitHub Pages.
